# Mobile-Architect-Programming
Event Tracker App – Project 3 Reflection

This mobile app was designed to help users keep track of their upcoming events in a simple, organized way. The goal was to create an app that makes it easy to log in, add events, view them in a list, and remove them when needed. It also includes SMS permissions to notify users about important reminders, making it more useful for people who rely on their phones to stay on schedule.

To support user needs, the app includes three main screens: a login screen for account creation and access, an event management screen that displays data in a list, and an SMS permission screen that checks and requests access for notifications. I designed the UI to be simple and user-friendly, with clear labels and buttons that make navigation easy. Keeping the interface clean helped ensure that anyone could use the app without confusion.

When coding the app, I focused on clear structure, reusable code, and consistent naming conventions. I used small helper classes for database operations and tested each feature as I built it to catch issues early. These strategies made debugging smoother and can definitely help me in future projects where organization and clarity are important.

I tested my app using the Android Emulator to make sure the database, login, and SMS features all worked correctly. This testing process showed how important it is to verify each part of the app separately before combining everything.

Overall, this project taught me how to connect UI design with backend functionality while keeping the user’s experience at the center. I’m proud of how the login and event management features turned out—they really demonstrate my understanding of user-centered design and mobile app development.
